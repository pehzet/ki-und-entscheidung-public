# KI und Entscheidung

Öffentliche Webfassung der Lehrpräsentation im Modul Future Skills von Philipp Zmijewski, Hochschule Osnabrück (2026).

## Link

Die Präsentation ist [hier](https://pehzet.github.io/ki-und-entscheidung-public) via GitHub Pages einsehbar.

## Aufbau

- [`index.html`](index.html) öffnet die Präsentation mit Navigationsleiste und PDF-Knopf.
- [`ki-und-entscheidung.pdf`](ki-und-entscheidung.pdf) ist die Druckfassung.
- Die HTML-Fassung enthält keine Sprechernotizen.
